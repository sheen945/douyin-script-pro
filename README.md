# douyin-script-pro

> 抖音爆款脚本全流程创作 + AI 视频影像化下游：多模型接力（豆包初稿 / DeepSeek 初稿 / Gemini 精修）+ 创意点火引擎 + 反平庸双重闸门 + 分镜/角色/图像/视频提示词生产线。

## 简介

douyin-script-pro 是一个 WorkBuddy / Claude Code 技能（Skill），把「写一条能活的抖音脚本」从灵感一路管到 AI 视频生成提示词：上游是脚本生产线（选题 → 结构 → 初稿 → 评分迭代 → 精修 → 包装交付），下游是影像化生产线（分场视觉锚定 → 角色表演档案 → 图像资产提示词 → 视频提示词），共 11+1 个阶段。

它解决的核心问题是：单模型写脚本「一类强一类弱」、AI 味重、不过审、不差异化。本技能用**智能分流**（温情/情感类给豆包 2.0 Pro，知识/历史/文化类给 DeepSeek V4 Pro，精修统一给 Gemini 3.6 Flash）、**官方算法六原则**（多目标打分/组合目标/握手模型/兴趣时钟/复审生存/原创探索）、**双重反平庸闸门**和**三道预检**（复审生存/戏剧动作/潜台词）把每一步都卡住。

适合：抖音内容创作者、短视频编导、用 AI 视频工具（即梦等）做片子、需要系统化选题与脚本方法论的人。

## 功能特性

- **创意点火引擎（阶段零）**：没想法时启动——趋势同步（抖音热搜/社会话题）→ 社会张力诊断（阶层/代际/性别/技术/文化五象限）→ 12 路奇想发散（反向/嫁接/放大/微小各三路）→ 三维度收敛打分，输出 Top 3 选题。
- **初稿模型智能分流**：情感故事/品牌温情/热点/挑战/记录流 → 豆包 2.0 Pro；知识干货/文化解读 → DeepSeek V4 Pro；类型无法判定时兜底用豆包。依据 2026-07-23 实测对比表（开头/网感/情感/逻辑/稳定性五维打分）。
- **HOOK-X 钩子矩阵 + 六种故事结构**：冲突/悬念/反常识/共鸣/数据震撼/身份代入/对比冲突/时间压迫 8 型钩子选 1 主 1 备；对账式真相揭露、角色互换、情感容器、穿越叙事、挑战叙事、真实记录流六种结构模板。
- **三道阶段预检**：阶段二「复审生存预检」（冲突落点必须正向，不消费特定群体）+「戏剧动作预检」（每场戏必须能写成「XX 想 [目标]，但 [阻碍]」）；阶段三「潜台词预检」（情绪不说破、不写拍不出来的内容、删掉说教）——方法论源自 @山音 编剧/导演大师（MIT 协议）。
- **300 分评分体系 + 迭代优化**：内容质量/算法适配/创新度/挑战专属四维度打分，240 分达标进精修，5 轮迭代上限，每轮展示详情。
- **双重反平庸闸门**：阶段四闸门一（无可替换句、5 秒记忆锚点、截图级金句、无万能段、人设辨识度）；阶段七闸门二（不可替代性、「卧槽」瞬间、3 秒停指、可砍铺垫、搜索命中）。
- **Gemini 精修（阶段六）**：六维度结构诊断（逻辑链/冗余度/支撑力/开头力/结尾力/节奏感）+ writing-polish 四原则（实实在在/聚焦轻重/说人话/格式克制）；禁用 Claude 系列做精修。
- **完整交付包（阶段七）**：标题 3 选 1、标签、BGM、封面、播放量预估、互动引导、发布时段建议（兴趣时钟对齐）、评论区运营方案（预埋 3-5 条评论 + 每条配作者回复话术，对齐官方握手模型）。
- **MVP 冷启动协议**：取脚本前 30-45 秒最小可行测试，72 小时内按完播/点赞/评论/转发/收藏/涨粉/主页点击 7 项多目标阈值判断反馈环。
- **可切条传播资产**：封面图方案、15 秒预告片、30 秒精华版、金句卡、评论预埋，一套脚本多次分发。
- **下游影像化生产线（阶段八~十一，懒加载）**：分场视觉锚定 → 角色表演档案（一致性档案 + 300-500 字表演主档案 + 声音提示词锁定）→ 图像资产提示词（纯中文、防失败铁律）→ 视频提示词（首帧锁定/空间调度/物理法则/灯光锁定）；可选支线「阶段十点五：镜头设计」（551 镜实测时长数据库）。
- **工程化协作机制**：模型接力提示词包（拼好初稿/精修指令包一键复制到对应模型窗口）、项目状态卡、回退协议（版本标注、不自动重做下游）、权威输入确认制。
- **三种运行模式**：标准流程（每阶段确认）、快捷模式（「快速出脚本」内部跑完全程直接出打包）、半自动模式（只在阶段一、阶段四停下确认）。

## 工作原理 / 技术栈

- **技能架构**：主文件 `SKILL.md` 管上游脚本全流程；下游专业模块与接力提示词放在 `references/` 目录按需懒加载，不常驻上下文——刻意避免往必经路径挂文件造成常驻负担（主文件内嵌的"每题必过"内容约 400 字）。
- **多模型接力**：本技能本身不直接调模型 API，而是生成「初稿指令包」「精修指令包」让用户复制到豆包 / DeepSeek / Gemini 对应窗口，拿回结果后继续流程；半自动模式减少打断次数。
- **官方算法对齐**：六原则来自抖音安全与信任中心官方文档（trust.douyin.com / 95152.douyin.com），所有阶段的创作决策必须服从。
- **方法论来源**：@山音 编剧/导演大师（戏剧动作/潜台词/镜头设计）、prompt-infinity-v3_3（创意点火引擎）、deep-writer-pro（六阶段+诊断+润色原则）、douyin-viral-content（9要素+300评分）、short-video-script（抖音适配）、AI STUDIO 洋子对话包（下游影像化四模块+总控路由）。

## 安装与使用

### 安装技能

把本仓库目录复制到技能目录，文件夹名保持 `douyin-script-pro`：

```bash
# WorkBuddy / CodeBuddy（用户级）
cp -r douyin-script-pro ~/.workbuddy/skills/

# 或 Claude Code
cp -r douyin-script-pro ~/.claude/skills/
```

项目级使用则复制到项目的 `.workbuddy/skills/` 目录。重启会话后通过触发词自动匹配。

### 触发方式

| 说法 | 进入流程 |
|------|---------|
| "写抖音脚本""创作抖音短视频" | 标准流程（直接阶段一） |
| "没想法""帮我想选题""最近什么火" | 从阶段零创意点火开始 |
| "快速出脚本" | 快捷模式（不展示中间过程） |
| "半自动""少打断我" | 半自动模式（只在阶段一、四确认） |
| "把脚本做成视频提示词""影像化" | 下游影像化流程（阶段八~十一） |
| "从XX阶段继续""只做XX" | 接力模式，跳到指定阶段 |

### 完整流程

```
【上游：脚本生产线】
阶段零  创意点火（趋势同步 → 张力诊断 → 12路发散 → 收敛打分）
阶段一  选题分析 + Brief + 主打行为信号 + 模型匹配
阶段二  HOOK-X 钩子 + 故事结构 + 分镜大纲（过复审生存预检 + 戏剧动作预检）
阶段三  填充初稿 + 9大爆款要素 + 合规审查（过潜台词预检）
阶段四  自查10项 + 300分评分 + 反平庸闸门一
阶段五  迭代优化（5轮上限，240分达标）

【切换 → Gemini 3.6 Flash】
阶段六  精修润色（六维诊断 + 四原则）
阶段七  包装交付 + 反平庸闸门二 + MVP冷启动 + 可切条资产

【下游：影像化生产线（references/ 懒加载）】
阶段八  分场与视觉锚定
阶段九  角色与表演档案
阶段十  图像资产提示词
阶段十点五  镜头设计（可选，精细分镜才进）
阶段十一  视频提示词
```

## 注意事项

- **模型可用性依赖**：分流方案基于 2026-07-23 实测（豆包 2.0 Pro / DeepSeek V4 Pro / Gemini 3.6 Flash），模型版本升级换代后需重新实测校准；Claude 系列（Opus 4.6/4.7/4.8/Fable 5）已明确弃用，精修不要用它。
- **需要用户接力**：初稿和精修由用户复制指令包到对应模型窗口执行，本技能不直接调 API——没有这些模型的访问权限时流程会断。
- **合规硬规则**：极限词、国家机构名、真实名人（去世 50 年内）、医疗功效、政治宗教敏感内容全程禁止；下游提示词输出前还有一道合规闸门。
- **下游懒加载纪律**：一次只加载一个 references/ 模块，执行完再决定下一个，防止编剧规则与镜头规则互相污染；只做脚本的会话完全不碰下游。
- **回退协议**：下游发现上游问题时切回对应阶段只修指定问题，新旧版本编号保留，不自动重做下游。
- **权威输入确认制**：用户上传的脚本/角色卡/资产图，只有明确说"以这些为准"后才作为权威输入。
