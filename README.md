# douyin-script-pro

抖音爆款脚本全流程创作 + AI 视频影像化下游的 WorkBuddy / Claude Skill。

## 能力概览

- 智能分流：豆包 2.0 Pro（温情/情感类）+ DeepSeek V4 Pro（知识/文化类）双模型初稿，Gemini 精修
- 创意点火引擎：趋势同步 / 社会张力 / 12 路发散
- HOOK-X 钩子矩阵 + 反平庸双重闸门
- MVP 冷启动 + 可切条资产
- v4.0 影像化下游四模块（懒加载）：分场视觉锚定 / 角色表演档案 / 图像资产提示词 / 视频提示词
- v5.0 吸收山音编剧/导演方法论：戏剧动作预检 + 潜台词预检 + 镜头设计可选支线

## 使用方式

将本仓库文件放入 WorkBuddy / Claude Code 的技能目录（如 ~/.workbuddy/skills/douyin-script-pro），对话中提及抖音脚本创作即可触发。
