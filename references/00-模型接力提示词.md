# 00 · 模型接力提示词包

> 用途：初稿用豆包/DeepSeek、精修用 Gemini，这三步都要把中间产物**手动带过去**。
> 本文件预置三段固定模板，跑到对应阶段时，把【】里的占位符填上当前项目内容，**整段拼好交给用户一键复制**，粘贴到对应模型窗口即用。
> 加载时机：阶段一确认模型后（拼初稿包）、阶段五达标后（拼精修包）。

---

## 模板一：豆包 2.0 Pro 初稿指令包（温情/情感/热点/挑战/记录类）

```
你是一位抖音爆款短视频编剧，擅长温情向、强网感、开头炸裂的脚本。请严格按以下要求写一条完整口播脚本初稿。

【选题】[填入选题]
【Brief】人设：[ ]｜受众：[ ]｜核心命题：[ ]｜内容立场：[ ]｜风格基调：[ ]｜金句方向：[ ]｜时长：[ ]秒
【主打行为信号】主：[完播/点赞/评论/转发/收藏/关注]｜副：[ ]（全篇设计服务于这两个信号）
【钩子】开头用 [HOOK-X 类型] 钩子：[填入钩子方案]，前 3 秒只做一个动作+一句旁白，不解释不铺垫
【故事结构】[填入结构类型与分段大纲，逐段列出]
【反差元素】[填入反差矩阵要点]

硬性要求：
1. 口播每句 10-20 字短句，纯口语，禁书面语；字幕每行不超一行
2. 前 3 秒视听双冲击（画面冲击+音效点睛），开头极短极炸裂
3. 每 15 秒一个冲突爆点；情绪按 [填入情绪递进线] 推进
4. 融入 9 大爆款要素：情感权力反转/认知重构/权威背书/宿命感/算法友好标签/金句传播性/完播率优化/互动钩子/BGM适配
5. 禁用：极限词（最/第一/唯一等）、国家机构名、真实名人姓名、医疗功效、空洞激励语、AI 味模板句
6. 冲突的落点必须正向（误解→化解），不制造对立、不消费特定群体
7. 台词不说破情绪，用动作表达；结尾金句不喊口号，落在具体动作或画面上
8. 结尾给一句 8-16 字对仗金句 + 一个互动提问（留缺口让人想评论）

输出格式：分段时间戳 + 画面描述 + 口播台词 + 字幕文案，逐段排列。
```

## 模板二：DeepSeek V4 Pro 初稿指令包（知识/文化/历史类）

```
你是一位知识类短视频编剧，逻辑严谨、文史功底深厚。请严格按以下要求写一条完整口播脚本初稿。

【选题】[填入选题]
【Brief】人设：[ ]｜受众：[ ]｜核心命题：[ ]｜内容立场：[ ]｜风格基调：[ ]｜金句方向：[ ]｜时长：[ ]秒
【主打行为信号】主：[收藏/关注/转发/完播]｜副：[ ]（知识类优先"收藏+复访""关注+追更"）
【钩子】开头用 [HOOK-X 类型] 钩子：[填入钩子方案]，悬念型/反常识型优先
【故事结构】[填入结构类型与分段大纲，逐段列出]
【逻辑链】[因果/并列/递进/对比/反转]，每 5-10 秒一个推进

硬性要求：
1. 口播每句 10-20 字短句，现代文口播，引用古文用字幕呈现；字幕每行不超一行
2. 知识准确、引用可查，不编造数据与史实；存疑处标 [待核实]
3. 干货按清单/步骤结构设计，制造"值得收藏反复看"的密度；结尾加"先码住"钩或下集预告
4. 每 15 秒一个认知冲击点；深化手法六选：补背景/讲机制/给案例/做对比/引申义/摆证据
5. 禁用：极限词、国家机构名、真实名人姓名（去世 50 年以上例外）、医疗功效、AI 味模板句
6. 台词不说破结论，让观众自己推出；结尾金句 8-16 字，落在具体画面而非口号
7. 预埋一个互动提问（留缺口，激发评论讨论而非引战）

输出格式：分段时间戳 + 画面描述 + 口播台词 + 字幕文案，逐段排列。
```

## 模板三：Gemini 3.6 Flash 精修指令包（所有类型通用）

```
你是中文短视频文案精修专家。下面是一条已达标的抖音脚本初稿，请只做润色，不改核心立意、不加大纲之外的内容。

【脚本全文】
[粘贴阶段五达标后的完整脚本]

【背景】类型：[ ]｜主打行为信号：[主]+[副]｜时长：[ ]秒｜人设：[ ]

分两步执行：

第一步 · 六维度结构诊断（先输出诊断，再动笔）
逻辑链是否闭环 / 冗余度（有没有万能段、同义重复）/ 支撑力（论据是否撑得住观点）/ 开头力（前 3 秒能否停住手指）/ 结尾力（金句是否有传播欲）/ 节奏感（是否每 15 秒有推进）
逐条给"好/差+具体建议"。

第二步 · 按四原则润色
1. 实实在在：删掉空洞句，抽象改具体，结尾不画蛇添足
2. 聚焦轻重：核心段落多笔墨，过渡三两句话带过
3. 说人话：禁用"值得注意的是/不可否认/赋能/洞见/践行/某种意义上/在当今社会/综上所述"；口播保持 10-20 字短句；保留原稿的个人语气
4. 格式克制：破折号全文不超两处，不混用中英文标点

红线：不新增极限词/机构名/名人；不改变已选定的钩子与行为信号设计；字幕仍不超一行。

输出：六维诊断 → 润色后全文（分段格式不变）→ 润色说明（改了哪、为什么）。
```

## 使用规则

- 跑到阶段二/三前，拼对应初稿包（豆包 or DeepSeek），整段发给用户复制；用户从外部模型拿回初稿后，继续在本会话走阶段四评分
- 阶段五达 240 分后，拼 Gemini 精修包；拿回精修稿后走阶段七包装
- 占位符从当前阶段产物里填（Brief 用阶段一、大纲用阶段二、行为信号用 1.2.5），不臆造
- 用户回复初稿/精修稿后，先核对是否违反红线（改核心、加极限词等），违反则指出并让用户回炉
