# 00 · 模型接力提示词包

> 用途：初稿用情感/知识档位、精修用精修档，中间产物需要**手动带过去**。
> 本文件预置三段固定模板，跑到对应阶段时，把【】里的占位符填上当前项目内容，**整段拼好交给用户一键复制**，粘贴到对应模型窗口即用。
> 加载时机：阶段一确认模型后（拼初稿包）、阶段五达标后（拼精修包）、用户回传后（过回传校验清单）；不想搬运就走「单模型降级路径」。
> 型号只是当前映射，档位名不变；换模型只改 SKILL.md 的档位映射表，本文件模板里的型号名可一并替换。

【钩子】开头用 [HOOK-X 类型] 钩子：[填入钩子方案]，前 3 秒只做一个动作+一句旁白，不解释不铺垫

2. 前 3 秒视听双冲击（画面冲击+音效点睛），开头极短极炸裂
3. 每 15 秒一个冲突爆点；情绪按 [填入情绪递进线] 推进

7. 台词不说破情绪，用动作表达；结尾金句不喊口号，落在具体动作或画面上

```
你是一位知识类短视频编剧，逻辑严谨、文史功底深厚。请严格按以下要求写一条完整口播脚本初稿。

【选题】[填入选题]
【Brief】人设：[ ]｜受众：[ ]｜核心命题：[ ]｜内容立场：[ ]｜风格基调：[ ]｜金句方向：[ ]｜时长：[ ]秒
【主打行为信号】主：[收藏/关注/转发/完播]｜副：[ ]（知识类优先"收藏+复访""关注+追更"）
【钩子】开头用 [HOOK-X 类型] 钩子：[填入钩子方案]，悬念型/反常识型优先
【故事结构】[填入结构类型与分段大纲，逐段列出]
【逻辑链】[因果/并列/递进/对比/反转]，每 5-10 秒一个推进

硬性要求：
1. 口播每句 10-20 字短句，现代文口播，引用古文用字幕呈现；字幕每行不超一行
2. 知识准确、引用可查，不编造数据与史实；存疑处标 [待核实]
3. 干货按清单/步骤结构设计，制造"值得收藏反复看"的密度；结尾加"先码住"钩或下集预告

5. 禁用：极限词、国家机构名、真实名人姓名（去世 50 年以上例外）、医疗功效、AI 味模板句
6. 台词不说破结论，让观众自己推出；结尾金句 8-16 字，落在具体画面而非口号
7. 预埋一个互动提问（留缺口，激发评论讨论而非引战）

输出格式：分段时间戳 + 画面描述 + 口播台词 + 字幕文案，逐段排列。
```

## 模板三：精修档指令包（当前：Gemini 3.6 Flash｜所有类型通用）

```
你是中文短视频文案精修专家。下面是一条已达标的抖音脚本初稿，请只做润色，不改核心立意、不加大纲之外的内容。

【脚本全文】
[粘贴阶段五达标后的完整脚本]

【背景】类型：[ ]｜主打行为信号：[主]+[副]｜时长：[ ]秒｜人设：[ ]

分两步执行：

第一步 · 六维度结构诊断（先输出诊断，再动笔）
逻辑链是否闭环 / 冗余度（有没有万能段、同义重复）/ 支撑力（论据是否撑得住观点）/ 开头力（前 3 秒能否停住手指）/ 结尾力（金句是否有传播欲）/ 节奏感（是否每 15 秒有推进）
逐条给"好/差+具体建议"。

第二步 · 按四原则润色
1. 实实在在：删掉空洞句，抽象改具体，结尾不画蛇添足
2. 聚焦轻重：核心段落多笔墨，过渡三两句话带过
3. 说人话：禁用"值得注意的是/不可否认/赋能/洞见/践行/某种意义上/在当今社会/综上所述"；口播保持 10-20 字短句；保留原稿的个人语气
4. 格式克制：破折号全文不超两处，不混用中英文标点

红线：不新增极限词/机构名/名人；不改变已选定的钩子与行为信号设计；字幕仍不超一行。

输出：六维诊断 → 润色后全文（分段格式不变）→ 润色说明（改了哪、为什么）。
```

## 使用规则

- 跑到阶段二/三前，拼对应初稿包（情感初稿档 / 知识初稿档），整段发给用户复制；用户从外部模型拿回初稿后，继续在本会话走阶段四评分
- 阶段五达标（标准型 240 / 挑战型 320）后，拼 Gemini 精修包；拿回精修稿后走阶段七包装
- 占位符从当前阶段产物里填（Brief 用阶段一、大纲用阶段二、行为信号用 1.2.5），不臆造
- 用户回复初稿/精修稿后，先过下面的「回传校验」，违反则指出并让用户回炉

## 回传校验清单（v5.3 新增，拿回稿子先过一遍再进下一阶段）

外部模型不共享本会话的 Brief 与大纲，它一定会"自作主张"。回传后按四组核，**任一组不过 → 指出具体位置让用户回炉或要求局部重写，不要带着问题往下走**：

**① 立意与结构（改没改核心）**
- [ ] 核心命题是否仍是阶段一定下的那一个？有没有被偷偷换成更"讨喜"的角度
- [ ] 钩子是否还是阶段二选定的 HOOK-X 类型？有没有被换回默认的悬念开场
- [ ] 分段是否与阶段二大纲一致？有没有加段、删段、调序
- [ ] 主打行为信号的设计是否还在（押收藏的有没有清单结构，押关注的有没有追更钩）

**② 合规红线（新增违规没有）**
- [ ] 有没有新混进极限词、机构名、真实名人姓名、医疗功效
- [ ] 冲突落点是否仍为正向？有没有把"误解→化解"写成"对立→不化解"
- [ ] 有没有为了煽情消费特定群体的痛苦、外貌、隐私

**③ 可拍性与语感（能不能拍、像不像人说的）**
- [ ] 有没有新增"他很紧张""内心涌起"这类拍不出来的描述
- [ ] 台词有没有把情绪说破、有没有角色在解释设定
- [ ] 口播是否仍在 10-20 字短句，有没有变回长句书面语
- [ ] 字数是否落在目标时长的预算区间内（4-5 字/秒）

**④ 格式完整性（能不能直接用）**
- [ ] 是否保留了「分段时间戳 + 画面描述 + 口播台词 + 字幕文案」的逐段结构
- [ ] 该标的 [待补充]/[待核实] 有没有被模型擅自编造填掉
- [ ] 结尾金句是否 8-16 字、是否落在具体动作而非口号

> 校验结果按「通过 / 局部回炉（指出段落）/ 整体重发」三档反馈给用户，不要只说"没问题"或"重写"。

## 单模型降级路径（v5.3 新增，不想跨窗口搬运时用）

接力不是必选动作。用户明确表示"不想来回复制"或在当前会话里就能拿到同等质量时，走降级：

1. **声明降级**：在阶段一输出里加一行 `⚠️ 已降级：全流程在本会话单模型执行，跳过模型接力`
2. **保留档位语义**：结构仍按情感/知识档位的偏好设计（情感类加重开头冲击，知识类加重逻辑与引用核验），只是换成本会话模型来写
3. **补偿动作（必做）**：
   - 阶段四评分时，把「网感/开头力」两项单独复核一遍（单模型最容易在这里同质化）
   - 阶段三照常过潜台词预检，阶段四照常过两道闸门——降级只降模型，不降关卡
4. **不假装接力**：不要在没有真正调用外部模型时，输出"已发给豆包/DeepSeek"之类的话术
5. **可随时切回**：用户后续想用接力，从当前阶段直接拼包发出即可，不必回退重跑
