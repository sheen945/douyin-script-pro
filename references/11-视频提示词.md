# 阶段十一模块：视频提示词（CINEDANCE 精简版）

> 由主技能 SKILL.md 在阶段十一按需加载。任务：把分场+角色档案+资产图转化为可直接投喂视频生成模型（Seedance / 可灵 / 即梦等）的**单镜头独立提示词**，纯中文，争取一次生成到位。
> 最终只输出提示词本身，不输出分析、不自检外显、不解释改了什么。

## 内部流程（静默执行，不外显）

1. 拆解：只提取当前镜头——在场角色、活跃@标签、场地、道具、动作、对白、时长、首帧、空间布局、光线方向。**移除**：未出场角色、过期@标签、场景编号、场记标题、"同上/继续自/如前所述"
2. 诊断：首帧会不会空镜？角色出场太晚？站位/视线会不会反转？道具会不会换手？运动会不会轻飘？有风险就加锁定指令
3. 开发：按下方架构构建
4. 交付：只给提示词

## 提示词架构（按此顺序，非每块都强制）

【场景语境】一两句说清本镜头发生什么，无前情提要、无场景编号
【活跃参考】只列本镜头用到的@标签，不捏造、不带过期标签
【首帧与空间调度】
【光学镜头】
【摄影机机位】
【动作时间轴】
【物理法则】
【灯光】
【音频】
【正向约束】（必要时局部内联"无X"锁定）

## 核心控制规则

### 首帧锁定
第一个可见帧已包含所有所需角色及正确站位。无空镜开场、无延迟出场。空间关系第一帧即可读。（用户明确要求空镜除外）

### 空间调度（每个人的位置都要定义）
- 屏幕位置 + 世界位置 + 与地标/他人的距离 + 身体朝向 + 视线方向 + 前中背景
- 身体朝向和视线方向分开写："躯干朝向X，眼睛锁定X"
- 禁用弱词："附近/旁边/周围/某处" → 改用强锚定："1米以内/背靠墙/手握门把手/站在标志牌正下方"

### 镜头决策（用视场角度数，不用毫米/光圈/品牌做主控）
- 面部特写：18°长焦（6-8米，背景压扁融化成散景）或 84°亲密广角（1-1.5米）
- 中景肖像：29°短中焦（4-6米）
- 环境与动作：47°标准（3-5米，自然透视）或 84°广角（环境延伸到边缘）
- 大场景地理：107°广角畸变校正
- 远距离观察：8°超长焦（20-25米，必须带前景遮挡）
- 一个镜头内不混合不兼容内容类别（肖像+大地理+微距=焦段漂移）；需要就硬切分镜
- 长焦至少带4个物理短语（如"背景压扁""奶油般焦外散景""对焦如刀锋锁定主体"）；广角至少带3个（如"前景身体更庞大""环境清晰可读""无长焦压缩感"）

### 多镜头连戏（有剪切时）
每次剪切保留：出场角色/地理/屏幕方向不越轴/视线/左右关系/光线方向/服装/伤口/道具/手部状态/情绪递进。剪切后动作不重置、角色不瞬移。只用硬切/突切/匹配剪辑/特写插入/反打/甩切；默认无淡入淡出叠化转场。

### 动作时间轴
按剧情需要分时间块，长短不一不平均："0:00-0:03：[位置+动作+摄影机行为]"。块间首尾连续覆盖总时长；一镜到底的动作必须在可用时间内物理可行。

### 物理法则
重力/质量/惯性/摩擦/重量转移强制执行。走路：脚后跟着地→重量转移→脚趾蹬地。液体：附着滴落染色顺重力。布料头发延迟飘动。无漂浮、无瞬移、无轻飘CG感、无滑步。

### 灯光（高优先级锁定，不是装饰）
- 必写：主光源、方向、摄影机在阴影侧还是受光侧、背景亮度、曝光优先级
- 逆光时：主体在摄影机和亮背景之间，面部允许陷入阴影，只有轮廓光/边缘光/眼神光揭示细节；严禁平淡正面光、美颜补光

### 对话
只说剧本带引号台词，无即兴发挥。说话角色嘴唇仅在念词时动，其他人静听。无画外音（除非明确）。需要干净对话：环境音自动压低；台词前后留白至少1秒静默。
- 角色说话时把声音提示词**一字不差**粘贴进音频字段；不说话则省略

### 语境隔离
提示词是与上下文完全隔离的独立文件：无场景编号、无前情提要、无未出场角色、无"又一次/和之前一样/紧接上一个镜头"。

### 密度控制
高密度：身份锚点/站位/首帧/视线/距离/手与道具状态/时间轴/光学/灯光/物理/对话。低密度：通用美描述/参考图已一目了然的细节。质量来自控制信号，不是字数堆砌。

## 静默自检（输出前，不外显）
- 所有@标签都用上了？过期的删了？
- 首帧正确？站位/视线/朝向清晰？距离锚定？
- 镜头焦段与内容匹配？灯光有防扁平锁定？
- 道具在正确的手？动作物理可行？时间轴合理？
- 对话只含剧本台词？无语境泄露？纯中文？
- 任一答案为"否"→修复后再输出

## 输出

每个镜头一条独立提示词（代码块）+ 下一句口令建议：「下一个镜头」或「全部完成」
