# 阶段九模块：角色与表演档案

> 由主技能 SKILL.md 在阶段九按需加载。任务：为 AI 视频生成建立两件事——①角色一致性档案（防跨镜头脸崩/人设崩）；②表演主档案（喂给视频模型的"表演层"内容）。核心公理：**表演是在压力下的行为，不是情绪的展示。**

## 第一部分：角色一致性档案（每个出场角色一份）

从定稿脚本和分场大纲提取，字段如下（全部纯中文，可拍摄、可观察）：
- 基础：年龄 / 体型 / 身份表层与底牌
- 外观锚点：第一眼画面印象（1-2句）、特殊标记、开场到高潮的服装物理变化
- 心理引擎：致命缺陷 / 显性渴望 / 隐性需求 / 一句话精神内核
- 声音特征：音高音色、口音、语速、情绪下的破音方式（锁定后全片不改）
- 标志物件：代表该角色的具体物品

**声音可辨测试**：任取一段台词不署名，能听出是谁说的才算通过；听不出→重做声音设定。

## 第二部分：表演主档案（300-500字，一段流畅中文）

模板（区块顺序固定）：
角色表演：[姓名]。[年龄体型姿态——身体承载过往经历]。[一句心理引擎]。声音特征：[音色、语速、情绪下转变]。关键习惯小动作：[小动作+触发条件；压力下的小动作；掩饰行为；面具表情+破裂条件]。步态风格：[命名+重心节奏描述]。然而，当[情绪触发点]时，[姿态/面部如何转变]。[可选：唯一软肋目标]。

编写规则：
1. 只写可观察行为——不写"他很紧张"，写"下唇颤抖、用嘴长吸一口气急促呼出"
2. 每个小动作必须带触发器：[小动作]+[何时/因何]，没触发器只是装饰
3. 步态要命名（如"权力步伐"），并拆解重心、步幅、手臂、头部
4. 每个档案至少一个"然而，当XX时……"面具破裂瞬间
5. 软肋目标只能有一个
6. 不写服装、不写摄像机、不写色彩——表演只驱动动作、面部、声音

## 第三部分：眼神细节（必填项，防死鱼眼）

- 视线追踪：目光随思考漂移、扫描、落回，绝不死锁一个点
- 眨眼与状态挂钩：压力下快速眨眼，掌控时缓慢从容
- 眼神光：湿润、有光、鲜活
- 眼睛先于头部到达目标；台词未出口，想法先从眼里读出

## 第四部分：场景改编（主档案是用来改写的，不是复制粘贴的）

每个镜头按当下状态重写主档案：
- 只写在场角色；恒定核心（声音/标志动作/眼神）每场不变
- 物理上做不出的行为要"转化"不"删除"（踱步的能量→坐姿的抖腿撕纸）
- 输出为一段流畅中文，不用列表和标题
- **呈现状态而非过渡**：写"出拳瞬间、争吵正酣"，不写"把手伸进包里准备挥拳"

## 第五部分：群像规则

- 群体反应像波浪错开，绝不同步
- 事件发生后最有价值的画面是旁观者的脸
- 威胁出现时一切突然静止，从喧闹到静止是最好的标点
- 强者安静不动，弱者烦躁大喊
- 状态有惯性：被磨平的角色要累积体现（更灰暗迟钝），不在场景间重置

## 质检（发送前）

- [ ] 目标是动词不是状态 / 有2-4个可见节奏点变化 / 反应在搭档台词中途就开始
- [ ] 手头有动作，中断动作用作强调 / 距离变化有动机
- [ ] 小动作都有触发器 / 面具有破裂条件 / 眼神细节已写明
- [ ] 状态而非过渡 / 无服装摄像机色彩混入
- 自评：0假人 1朗诵者 2勤勉者 3熟练工 4活生生的人 5磁石（同时演两层真实）。特写镜头低于4分必须重写

## 输出

角色一致性档案 + 表演主档案 + 声音提示词（1-2句带引号，锁定不改）+ 质检结果 + 下一句口令建议：「确认档案，生成图像资产提示词」
