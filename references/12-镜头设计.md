# 阶段十点五模块：镜头设计（可选支线）

> 由主技能 SKILL.md 在阶段十点五按需加载。任务：在「阶段八分场」和「阶段十一视频提示词」之间补上缺失的镜头层——决定每个镜头为什么存在、镜头怎么成组、每个镜头给几秒。
> **本模块不是必经环节。** 只在用户要求精细分镜 / 参赛精品 / 商单高质量稿时进入；常规脚本从阶段八直接跳到阶段十一。

## 进入条件（防误入）

进入：
- 用户明确说「精细分镜」「按专业分镜来」「这条要做参赛作品 / 商单精品」
- 阶段八分场完成后，用户主动要求「再细一层」

- 常规脚本生产（阶段八 → 阶段十一直通）
- 快捷模式

## 一、叙事目的：每个镜头必须回答的问题

一个镜头存在的唯一理由是它承担了叙事目的。分析分两层：

**结构层（这个镜头在干什么）**
- 交代信息（人物 / 空间 / 时间 / 规则）
- 建立或强化角色特征
- 推进情节（制造冲突 / 升级冲突 / 翻转）
- 埋设或回扣伏笔
- 呈现核心命题
- 首尾呼应
- 节奏调节（呼吸点）

**执行层（想让观众产生什么效果）**
- 制造不安 / 压迫 / 窒息
- 控制视线、引导注意力
- 营造氛围（温暖 / 荒凉 / 疏离）
- 制造时间感（压缩 / 拉伸 / 停滞）
- 用视觉隐喻传达不可言说的内容
- 打破观众预期

**剔除规则**：一个镜头找不到任何叙事目的 → 删掉。一场戏里超过一半镜头找不到目的 → 这场戏该合并或重做。

**写法**：一句话同时说清「做什么」和「为什么这么做」，具体到视听手段。
- ✗「展现他们关系变差」
- ✓「用背对背构图展现疏离，桌上两副碗筷只动了一副」

## 二、镜头组：让镜头成组，不要散着

一个叙事目的常常由一组镜头共同完成。镜头组比场景小、比单镜头大。

| 组类型 | 组内关系 | 典型用途 | 组内镜数 |
|--------|---------|---------|---------|
| 蒙太奇组 | 并列 | 建立氛围、展示规模、压缩时间 | 3-8 镜 |
| 递进组 | 层层加码 | 角色介绍、情绪升级、荒诞累积 | 3-5 镜 |
| 因果组 | 动作→反应 | 对话正反打、攻防 | 2-4 镜 |
| 对比组 | 互相映照 | 前后呼应、反讽、并行 | 2-4 镜 |

节奏规划时就要标出镜头组划分，决定后续哪些镜头是一组的。

示例：
```
【场景2：楼道 / 夜】
  组A「人物名片」（递进组，3镜，约5秒）：快切建立角色身份和核心特征
  组B「加班蒙太奇」（蒙太奇组，4镜，约6秒）：展示日复一日
  → 全场景预估：约11秒
```

## 三、动作-反应：镜头之间的叙事逻辑

最基本单元：一个「动作」镜头 + 一个「反应」镜头。
动作 = 引发变化的事件（一句台词、一个行为、一个信息）；反应 = 它对世界产生的影响（另一个角色的表情、环境变化、沉默本身）。

抖音最实用的 6 种变体：

1. **标准型**：动作→反应。最基础，撑骨架，占比最大。
2. **反应前置型**：先给结果再给原因。先看到他跪在地上，再看到地上摔碎的手机。制造悬念。
3. **反应省略型**：刻意不给反应，直接切走或黑屏。留白让观众自己补——想象的比拍出来的更狠。**全片 1-2 次，多了就是偷懒。**
4. **动作隐藏型**：动作只在声音里（画外一声响），画面停在反应上。
5. **对比并置型**：两个画面形成对比（同画面内或相邻镜头），不用台词解释，观众自己看出来。
6. **链式衔接型**：一个镜头同时是上组的反应和下组的动作，像多米诺，叙事停不下来。

**70/30 法则**：70% 的镜头用常规方式撑骨架，30% 的出彩设计造记忆点。
- 出彩镜头要打在叙事重心上（钩子、转折、结尾）
- 出彩镜头前后最好都是常规镜头——靠「正常」反衬「不正常」
- 连续两个出彩镜头就失效了，它变成了新的常规

## 四、切镜连接：防跳轴、防景别乱跳

**景别连接**
- 相邻景别（全景→中景、中景→特写）最平滑，占多数
- 跨级跳切（全景直跳特写）冲击力强，用在惊讶 / 翻转 / 情绪断裂处，别滥用
- 连续同景别超过 4 个 → 单调，需要变化

**场景内推进方向**
- 推近（远→近）：从环境进入人物，最自然
- 拉远（近→远）：抽离感、揭示更大空间，常用在段落收尾
- 弹跳（中→特→中）：先强调细节再回环境，最常见的三镜序列

**场景转换**
- 全景开场法：新场景用全景交代「换地方了」，最稳妥
- 细节开场法：新场景用特写开场，制造悬念
- 情绪桥接法：上下场在情绪或视觉质感上呼应
- 硬切对比法：两场视觉风格强对比，对比本身就是叙事

**镜头组内连接**
- 蒙太奇组：同景别或相近景别，靠内容变化推进
- 递进组：景别逐步推近，信息层层递进
- 因果组：动作-反应交替，随事件升温可逐步推近
- 对比组：硬切，景别可相同可跨级

**防翻车三问**
- 越轴了吗？（相邻镜头里人物的左右关系是否翻转）→ 要么补一个过渡镜，要么明确是刻意为之
- 视线方向对吗？（A 看右，B 就该看左）
- 相邻镜头的景别 / 角度是否有视觉逻辑？

## 五、镜头时长数据库（本模块核心资产）

### 5.1 实拍短片实测基准

数据来源：山音导演大师基于 9 部短片、551 个有效镜头的统计分析。

| 指标 | 数值 |
|------|------|
| 平均镜头时长 | 4.2 秒 |
| 中位数 | 3 秒 |
| 1-5 秒镜头占比 | 76% |

**按叙事目的分档：**

| 叙事目的 | 基准时长 |
|---------|---------|
| 推进 / 升级 | 2.5-3.5 秒 |
| 交代 / 建立 | 4-5 秒 |
| 展现 / 呈现 | 4-5 秒 |
| 情绪 / 氛围 | 4-5 秒 |
| 呼应 / 闭环 | 4-5 秒 |
| 转折 / 翻转 | 5-7 秒 |
| 升华 / 主旨 | 6-10 秒 |

**按内容表达量**（一个镜头内要观众「读取」几层信息）：单层 2-3 秒，每多一层加 2-3 秒。多层信息 6-8 秒；综合段落（长镜头调度 / 情绪留白）10-15 秒。

**按景别**：特写 2-4 秒 / 中景 3-5 秒 / 全景 4-5 秒 / 远景 5-7 秒 / 景别转换镜头 8-12 秒。

**按镜头组**：快切蒙太奇组 1-2 秒/镜；递进介绍组 2-3 秒/镜；标准叙事组 3-5 秒/镜；情绪留白组 5-15 秒/镜。

**通用上限**：单镜尽量不超过 15 秒。超过必须有明确意图，且镜头内部要有变化（动作 / 焦点 / 光线），否则观众走神。

### 5.2 抖音适配修正（推导建议值，非实测）

抖音 30-120 秒比短片（3-7 分钟）密度更高，单镜应更短。以下为按比例推导的建议区间：

| 段落类型 | 抖音建议时长 |
|---------|-------------|
| 开头钩子（前 3 秒） | 0.8-1.5 秒/镜，快切 |
| 冲突 / 推进段 | 1.5-2.5 秒/镜 |
| 交代 / 建立段 | 2.5-3.5 秒/镜 |
| 情绪 / 转折段 | 3-4 秒/镜 |
| 结尾金句 / 升华 | 3-5 秒/镜，可留白 |
| 整体均值参考 | 2-3 秒/镜 |

> 说明：5.1 是实测数据，可直接引用；5.2 是按「时长缩短 → 密度提高」推导的建议区间，实际以你成片数据回填校准为准。

## 输出

按场景分批输出「拍摄级镜头清单」，每镜包含：
镜号 / 时长 / 景别 / 画面内容 / 声音 / 叙事目的 / 所属镜头组

分批规则（防暴走）：
- 30-60 秒成片：按场景分 2-3 批
- 60-120 秒成片：按段落分 3-5 批
- 每批输出后暂停确认

确认后进入阶段十一，把这份清单逐镜转成视频提示词。

下一句口令建议：「确认镜头清单，进入视频提示词」
